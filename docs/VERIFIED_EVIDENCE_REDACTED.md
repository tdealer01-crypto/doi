## AI Agent System integration scope

The private production architecture combines AI reasoning, Core Spin orchestration/state, Spacetime governance, approved execution adapters and evidence on one governed path. Planning, plan binding, approval, tool execution, audit and evidence are not treated as separate ungoverned shortcuts.

The verified public claim is intentionally narrower than “fully autonomous in every environment.” The evidence supports the tested control relationships: an AI can propose and continue work, Core Spin can carry job progress forward, mutating actions can pause for exact approval, authorized tools can execute, and verified results can be recorded for subsequent continuation.

Automation features such as sequencing, retry/resume, handoff and checkpoints remain subject to the same execution authority boundary. A retry or next reasoning round does not by itself grant permission to perform a side effect.
